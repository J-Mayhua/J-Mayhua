## 📌 Proyectos destacados

### 🏥 Sistema de Gestión Clínica
Aplicación web orientada a la gestión de pacientes, citas médicas, personal e historial clínico.
**Tecnologías:** PHP, MySQL, HTML5, CSS3, JavaScript.
🔗 [Ver proyecto](https://github.com/JMayhua/sistema-gestion-clinica)

### 🛍️ Sistema de Gestión de Tienda de Ropa
Aplicación para gestionar catálogo de productos, ventas, comprobantes e inventario.
**Tecnologías:** PHP, MySQL, HTML5, CSS3, JavaScript, Bootstrap.
🔗 [Ver proyecto](https://github.com/JMayhua/tienda_ropa)

### 👮 Sistema Policial de Gestión de Incidencias
Gestión y seguimiento de incidencias delictivas: registro, asignación de casos, geolocalización, carga de evidencias y reportes en PDF.
**Tecnologías:** PHP, MySQL, JavaScript, PDO, FPDF, Google Maps API.
🔗 [Ver proyecto](https://github.com/JMayhua/gestios-de-incidencias-delictivas)

### 🤖 Bot de Cobros por WhatsApp (API UCRM)
Automatización de cobranzas integrada con la API REST de UCRM: envío de mensajes, procesamiento de pagos y notificaciones.
**Tecnologías:** Node.js, Express, Axios, PM2.
🔗 [Ver proyecto](https://github.com/JMayhua/bot-cobros-api-whatsapp-web)

### 🤖 Bot de Cobros por WhatsApp (WPPConnect + OCR)
Automatización de recordatorios de pago y procesamiento de comprobantes mediante OCR, integrada con UCRM.
**Tecnologías:** Node.js, WPPConnect, Tesseract.js, Nodemailer.
🔗 [Ver proyecto](https://github.com/JMayhua/bot-cobros-whatsapp-wppconnect)
